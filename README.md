# Remembering Rob

A standalone memorial map for Rob's scattering places, photos and videos.

This project is intentionally separate from the G. Konopka Art website.

## Structure
- `index.html` — public memorial map
- `uploads.json` — gallery items synced from Dropbox
- `scripts/sync_dropbox.py` — imports Dropbox uploads into the matching location gallery
- `.github/workflows/sync-dropbox.yml` — scheduled/manual sync

## Dropbox folders
- Slaters Bridge
- Colorado River
- Emerald Cave
- Giants Causeway
- Cwm Idwal
- Glenariffe Coast
